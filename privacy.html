What AutoVideo is

AutoVideo is a personal tool used only by its developer, who is also the owner of the YouTube channel it works with.

Google user data accessed

Through Google OAuth, AutoVideo requests permission to (1) upload videos to the authorizing user's YouTube channel and (2) view basic YouTube account data in read-only mode, namely the view and like counts of the videos the tool uploaded.

How the data is used

The upload permission is used only to publish videos created by the tool. The read-only permission is used only to read view and like counts, which help decide what content to create next. The data is not used for advertising, profiling or any other purpose.

Storage, sharing and retention

The only credential stored is an OAuth refresh token, kept as an encrypted secret in the developer's private code repository. View and like counts are stored in the same private repository. No Google user data is shared with, sold to, or transferred to any third party.

Google API Services User Data Policy

AutoVideo's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

AutoVideo uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service and the Google Privacy Policy.

Revoking access and deletion

Access can be revoked at any time at https://myaccount.google.com/permissions. To request deletion of any stored data, write to the contact address below.
